Ques Addon
Meteor Client addon for Minecraft 1.24 (Fabric).

Features
Chunk Finder (new / old chunks)
Amethyst Cluster Finder (grown = old area)
Light ESP (spawnable blocks)
Storage ESP
Base Finder

Requirements
Java 17
Fabric Loader
Meteor Client
Minecraft 1.24

Build Instructions
```bash
git clone https://github.com/YOURNAME/ques-addon.git
cd ques-addon
gradlew build
